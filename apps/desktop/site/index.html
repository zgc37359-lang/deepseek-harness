Harness Desktop

DeepSeek Harness 的 Windows 桌面客户端。完整 Agent 运行时在主进程内运行，通过白名单 IPC 与界面通信——没有本地服务器，没有浏览器依赖。

功能

  • 进程内运行时 完整 Harness 插件树运行在主进程内，零 localhost 端口、零网络监听；界面通过白名单 IPC 桥通信。
  • 托盘常驻 关闭窗口即隐藏到托盘，随时从托盘打开主窗口或新建会话。
  • PowerShell 执行协议 Agent 内置 Windows PowerShell 5.1 执行规范：-LiteralPath、单阶段工具调用、Get-Command 先查参数、-WhatIf 先验证，降低 Windows 命令出错率。
  • 自动更新 基于 electron-updater，从 GitHub Releases 自动检查、下载、安装，标题栏常驻入口。
  • 加固渲染层 渲染进程启用 sandbox 与 contextIsolation，白名单 preload API；主进程是唯一的系统能力边界。
  • 持久化授权 按工作区管理 Agent 工具调用权限，持久、可撤销，审批记录清晰。
  • 诊断导出 一键导出主日志与版本/环境快照，便于问题反馈。
